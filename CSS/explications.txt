EXPLICATIONS DU CSS :

CCS = Cascading Style Sheet, qui veut dire en Français Feuilles de style en cascades.
Déf : Le CSS est un langage qui sert à mettre en forme et stylisé le contenu HTML;

Il permet de modifier l'apparence d'une page web en appliquant des styles tels que : les couleurs, tailles, formes.

On peut dire que le HTML construit la structure de la page tandisque le CSS la rend belle et agréable à visionner.

POURQUOI UTILISER DU CSS :
Sans CSS, une page HTML est tres simple et peu attrayante.
Le CSS permet de donner une  belle apparence aux pages web, ameliorer l'exeperience utilisisateur.

LES AVANTAGES DU CSS :
- Séparer le contenu HTML de la presentation.
- Reduit la repetition du code.
- facilite la maintenance des pages web.
- Permet de modifier rapidement l'apparence de plusieurs pages.
- Ameliorer de créer des sites modernes et responsives.

LES VERSIONS DU CSS :
CSS1 : Permiere version publié en 1996, elle intoduit les premieres regles de mise en forme.

CSS2 : Publé en 1998, ajoute de nouvelle fonctionnalité comme le, positionnement des élements.

CSS3 : La version actuelle moderne du CSS.

FONCTIONNALITE DU CSS :
Le navigateur suit generalement ces etapes :
- lit le fichier HTML.
- Il trouve les balises html.
- lit les regles CSS.
- il applique les styles aux elemest HTML.
- il affiche la page web avec sa mise en forme.

3 FACONS D'INTEGRER LES REGLES CSS :
- CSS en ligne
- CSS interne
- CSS externe

LE SYNTAXE CSS :
La syntaxe CSS est la maniere correcte  d'ecrire une regle CSS en fait que le navigateur puisse l'interprete et appliquer le style aux elements HTML.

UNE REGLE CSS EST COMPOSER DES TROIS ELEMENTS PRINCIPAUX :
* Selecteur : il permet de ciblé un ou plusieurs elements HTML pour les appliquer du Style.
- Selecteur Universel qui est (*) Permet des selections tous les elements de la page.
- Selecteur par balise permet de selectionner tous les elements ayant les meme nom des balises HTML.
- Selecteur par (class="") permet d'appliquer un meme style à plusieurs elements.
- Selecteur par Identifiant (id="") permet de cibler un element unique dans les contenus HTML.
- Selecteur groupe (h1, p, h3, .important, #principal) permet d'appliquer le meme style à plusieurs elements HTML differents.
- Selecteur descendat (div p {color: blue;}) permet de cibler un element qui se trouve à l'interieur d'un autre element. 
- Selecteur direct (div > p {color: red;}) cibler uniquement les elements qui sont les enfants direct.
- Selecteur d'attributs (input[type="text"] {background-color: brown;}) permet de selection un element selon ces attributs.

- text-align: center;

- text-transform: uppercase pour majiscule, lowercase pour minuscule et capitalize pour la premiere lettre en majiscule; (pour changer la capitalisation de texte)
- line-height: 1.3; pour ajouter les interlignes.
- letter-spacing: 8px; pour ajouter de l'espace entre le ligne.
- word-spacing: 10px; pour ajouter de l'espace entre le mot.
- text-Shadow: 10px(horizontal) 20px(verticlal) 5px(floue) red; pour ajouter une ombre sur le texte.
- Propriété racourcis : font: italic Blod 30px arial;
                        border: 1px solid blue; pour entourer avec un ligne un texte, une image ou une div.
- border-width: 5px; mais aussi : 12px(Haut) 15px(Droite) 10px(Bas) 13px(Gauche);
- border-style: solid(ligne continue) ou dashed(ligne en trait) ou double(double ligne);
- border-color: red; pour les couleurs des bordures mais si il ya border-style: none; il ne peut accepter.
- border-right: 8px dashed red; ou  border-left: 5px double green; ou border-bottom: 2px solid blue; ou border-top: 4px solid yellow; 
- border-raduis: 20px; pour arrondir les coins.
- border-top-left-raduis: 20px; pour arrondir le coin specifié et autres.
- outline: 5px solid blue; il arrondir à l'exterieur de l'element.
- box-Shadow: 5px(x: horizontal) 5px(y: verticlal) 2px(floue) red; permet d'ajouter une ombre autour d'un element.
* Chaque element est composer des margin: espace exterieur entre un élément et les autres éléments; border: ; padding: espace interieur entre le contenu et les bordures, content: c'est lui le contenu.
- padding(recommande d'utiliser le pixel): 20px(en haut et en bas) 40px(en gauche et en droite); si c'est deux valeurs.
            20px(en haut) 40px(gauche et droite) 30px(en bas);   si c'est trois valeurs.
            20px(en haut) 40px(en droite) 30px(en bas) 10px(en gauche); si c'est quatre valeurs.
- margin(recommande d'utiliser le pixel) : 20px(en haut et en bas) 40px(en gauche et en droite); si c'est deux valeurs.
            20px(en haut) 40px(gauche et droite) 30px(en bas);   si c'est trois valeurs.
            20px(en haut) 40px(en droite) 30px(en bas) 10px(en gauche); si c'est quatre valeurs.
            margin: auto; pour centre l'element.
--- box-sizing : border-box; souvent le navigateur donne au contenu certaines propriété par defaut donc il est recommande de le mettre dans un selecteur universel (* {box-sizing: border-box;})
* les dimensions : - width, height, max-width, max-height.
- width: 50%(pour la responsive); permet de modifier ou regler la largeur d'un element.
        min-width: 300px; donc l'element ne peut avoir moins de 300px par rapport à l'écran et toujours en pixel.
        max-width: 1250px donc l'element ne peut pas depasser le 1250px par rapport à l'écran et toujours en pixel.
- height: 50%(pour la responsive); permet de modifier ou regler la hauteur d'un element.
        min-height: 300px; donc l'element ne peut avoir moins de 300px par rapport à l'écran et toujours en pixel.
        max-height: 1250px; donc l'element ne peut pas depasser le 1250px par rapport à l'écran et toujours en pixel.
- overflow: visible; il peut etre que le contenu qui depasser peut etre un div.
            hidden; donc le contenu qui depasse doit etre caché.
            scroll: permet à scroller pour voir le contenu qui depasse.
            auto; le navigateur lui meme va ajouter la barre de scroll pour s'adapter au contenu qui depasse.
- list-style-type: cirle, square, none; pour la liste non-ordonnée.
                        decimal, upper-; pour la liste ordonnée.
- list-style-position: inside, outside; pour la position de puce.
- list-style-image: url("./images/afrixglobal.png"); mais pas souvent utliser.
Raccourcis: list-style: decimal inside url("./images/afrixglobal.png");
- Pour styliser un tableau : table, th, td{ border: 1px solid black} est c'est recommande avec CSS pas dans HTML.
(Et pour enlever les aspacement du bordure il faut border-collaspe: collaspe;)

* Unités :
- Les unites absolues sont des unites qui ont de taille fixe (le pixel).
- Les unites relatives et utliser pour le responsives depend de la taille d'un autre element(element parent) ou l'écran ( rem), ( em=16px peut changer avec l'imbrication et les composants), ( %).
- L'unite (rem) depend de la taille(la police) de l'element racine (<html lang="fr">).
- L'unite (vw) egalement 1% de la largueur de l'ecran (50vw egale 500px) il est recommande de l'utilser au lieu de %.
- L'unite (vh) egalement 1% de la hauteur de l'ecran (50vh egale aussi 500px) il est recommande de l'utilser au lieu de %.
